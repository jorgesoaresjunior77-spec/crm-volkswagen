          Dados e backup

          Os dados ficam salvos automaticamente neste navegador (localStorage), no computador onde você está usando o app. Isso funciona sempre que você abrir este mesmo arquivo HTML pelo mesmo caminho, mesmo sem internet.

          Se quiser um arquivo de verdade guardado numa pasta (para copiar, enviar por e-mail ou sincronizar no Google Drive/OneDrive), use "Salvar também numa pasta" no topo — funciona no Chrome e Edge. Nos demais navegadores, use Exportar backup e depois Importar backup para restaurar.

          ☁️ Sincronização em Nuvem compartilhe os dados entre você e os vendedores, em qualquer computador

          Com isso conectado, os dados deixam de ficar presos neste computador: todos que usarem o mesmo link e o mesmo "código da loja" abaixo enxergam e editam os mesmos dados, quase em tempo real. Sem isso, o app continua funcionando normalmente, só que salvando apenas neste navegador.

          Passo a passo pra pegar os 2 primeiros campos: crie uma conta grátis em supabase.com → crie um projeto → rode a instrução SQL que o Claude te passou (cria a tabela) → em Project Settings → API, copie a Project URL e a chave anon public.

            ⚙️ Regra Atual — como ler a próxima política
            Essas configurações ficam salvas de um mês pro outro. Toda vez que você anexar um PDF novo de política, o sistema já aplica essas regras sozinho, sem precisar pedir de novo.
            Como o sistema decide qual bônus vale:
            1º — a validade: qual faixa de data cobre o faturamento no atacado daquele carro (calculado a partir dos dias em estoque).
            2º — a taxa de financiamento escolhida pelo cliente, quando a política tiver mais de uma opção de taxa pra mesma faixa. Se o cliente for pagar à vista, isso não se aplica.
